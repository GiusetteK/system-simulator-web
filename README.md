# System Simulator Web

A small browser-based version of the offline terminal simulator. It generates fictional telemetry locally and has no backend or external dependencies.

## Run locally
Open `index.html` in a browser, or start a local server with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once the deployment finishes, the site will be available at:

https://giusettek.github.io/system-simulator-web/

The simulator is a fictional offline demo; it does not connect to real devices or networks.
